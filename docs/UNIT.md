# 단위 주의

경매 낙찰가는 10원, 1원까지 거의 내려가지 않는다.
어쩌다 나오는 수는 있지만, 왜만하면 100원 또는 1,000원에서 끊는다.

## 규칙

- 빈칸 빙고는 100원 자리, 또는 1,000원 자리까지만 돌린다.
- 10원 칸과 1원 칸은 빈칸으로 두지 않는다.
- 그 두 칸은 화면에 보일 때 0으로 고정한다.
- 사용자가 쓰는 앞자리는 의도로 정하는 구간이다.
- 돌리는 구간은 고민은 되지만 실질 의미가 작은 끝자리다.

## 화면

예시: 4 1 2 [ ] [ ] 0 0

- 412는 사용자 입력
- 대괄호 두 칸만 빙고
- 마지막 00은 10원·1원, 고정

단위 선택은 두 가지다.

- 1,000원 단위: 빈칸은 천원 자리까지. 백·10·1원은 0.
- 100원 단위: 빈칸은 백원 자리까지. 10원·1원은 0.
