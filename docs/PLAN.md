# 낙찰가 빈칸 빙고 앱 기획안

별도 앱으로 먼저 만든다. 본 경매 서비스와 분리한 대기용 놀이다.

## 한 줄 정의

경매 낙찰가(또는 입찰 후보가) 사진을 올리고, 앞자리는 사용자가 직접 쓴다. 나머지 빈칸만 빙고처럼 돌려 채운다.

## 왜 필요한가

- 3자리까지는 사용자 의지로 정한다.
- 4자리부터는 실질적 의미가 작지만, 입찰 전에 고민이 된다.
- 그 고민을 놀이로 넘긴다. 예측·내기·복권이 아니다.

## 사용 흐름

1. 경매 낙찰가·사건 화면을 사진으로 찍는다.
2. 앱이 사진을 위에 붙인다. (초기에는 OCR 없이 배경만)
3. 금액 칸이 나온다. 기본 5칸, 만원 단위.
4. 앞 3칸은 사용자가 직접 입력한다.
5. 뒤 2칸은 빈칸. 돌리기를 누르면 0~9가 빠르게 돌다 멈춘다.
6. 멈춘 숫자가 오늘의 나머지다.
7. 예: 앞자리 412 + 빙고 37 = 41,237만원.

## 화면

- 사진 올리기 (카메라 또는 앨범)
- 숫자 칸 (잠긴 칸 / 빈칸)
- 빈칸 돌리기
- 결과 금액 한 줄
- 다시 하기

## 범위 제한

- 실제 입찰·낙찰 예측이 아니다.
- 돈을 걸고 맞히면 나눠 주는 구조가 아니다.
- 법원경매정보 스크래핑을 하지 않는다.
- 사진은 기기 안에만 두고, 서버에 올리지 않는 것을 기본으로 한다.

## 나중에 붙일 수 있는 것

- 사진에서 금액 영역만 자르기
- 앞자리 개수를 2~4자리로 바꾸기
- 빈칸을 1칸 또는 3칸로 바꾸기
- 오늘의 빈칸 기록을 기기에만 저장
- 본 경매 앱 대기 화면에서 열 수 있게 연결

## 먼저 만들 것

- PWA 한 장
- 사진 첨부
- 앞자리 입력
- 빈칸 스핀
- 결과 표시
